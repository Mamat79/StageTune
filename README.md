# StageTune

Ce dépôt est réservé à la distribution de StageTune : installateurs, notices, notes de version et empreintes SHA-256.

La première préversion publique est en préparation. Aucun installeur n’est encore proposé dans ce dépôt. Les versions d’essai seront identifiées comme préversions et accompagnées de leurs limites de vérification.

Les sources et l’historique de développement sont conservés séparément. Ce dépôt ne contient pas le code de l’application.

Pour vérifier un téléchargement Windows, comparer son empreinte SHA-256 au fichier de contrôle publié avec la même version. Conserver une sauvegarde des données avant tout essai ou remplacement d’une installation.
